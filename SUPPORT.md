# Support

CharterMesh is pre-alpha community software.

- Use GitHub Discussions or a question issue for setup and usage questions.
- Use a reproducible bug issue for defects; include Node version, operating
  system, command, expected result, and sanitized output.
- Use **Security → Report a vulnerability** for security issues.

Never attach credentials, `.chartermesh/state.db`, artifacts containing private
data, environment dumps, or absolute private project paths.
