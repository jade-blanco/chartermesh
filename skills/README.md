# CharterMesh portable skills

These Agent Skills follow the open `SKILL.md` package format and are licensed
under Apache-2.0 with the rest of CharterMesh.

Bootstrap copies them into `.chartermesh/skills/` only after approval of the
exact file plan. A model or agent should read only the skill relevant to its
current WorkItem.

- `web-research`: source-grounded current research
- `repository-diagnostics`: read-only repository diagnosis
- `small-model-evidence`: evidence discipline for local/small models
- `integration-review`: external skill/MCP/adaptor review gate
